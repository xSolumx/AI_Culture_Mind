# Contributing

**Research author and maintainer:** Hayden Austin

Contributions are welcome when they preserve the repository's claim-separated
and provenance-first research contract.

## Documentation and evidence rules

1. Update the owning programme charter when a result changes a current claim.
2. Keep preregistrations and dated result reports append-only after their
   freeze; issue a correction or amendment instead of silently rewriting them.
3. Store completed machine evidence beside the controlling result document and
   record its validation or hash contract.
4. Distinguish theorem, exact reduction, empirical result, falsification
   evidence, negative result, historical statement, and open claim.
5. Never promote scan parity, an algebraic identity, a smoke test, or a
   synthetic mechanism result into model-quality evidence without the required
   matched experiment.
6. Use relative repository links and run the documentation checker before
   proposing a change.

```powershell
python tools/check_repository_docs.py
```
