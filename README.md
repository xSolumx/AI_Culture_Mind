# AI Culture Mind

Research workspace for geometric-algebra sequence models, recurrent state-space
models, and controlled neural-network experiments.

## Projects

- `Spin8-Triality-Research` — standalone, theorem-focused Spin(8) triality
  repository, linked here as a Git submodule.
- `SSM-Models` — mechanistic recurrence harnesses, ablations, and archived
  experimental evidence.
- `SpinorModel` — original compact geometric-algebra model prototype.
- `Spin8-SSM-Benchmark` — matched-path empirical benchmarks and baselines.

Large model weights, downloaded datasets, generated caches, and raw process logs
are intentionally excluded from Git. Reproducible research outputs should be
stored as structured JSON plus a concise Markdown interpretation.

Clone the repository and its theorem submodule with:

```bash
git clone --recurse-submodules https://github.com/xSolumx/AI_Culture_Mind.git
```
