# Spin(8) Five-Probe Identifiability Gate

**Frozen:** 2026-08-03, before any training result from this harness.

## Question

How little transformed-state evidence is required to identify one shared
Spin(8) action across the vector and two chiral-spinor representations?

The preceding blind joint-action experiment supplied 63 scalar constraints per
token and recovered a 28-parameter shared action. A prospective differential
rank audit now suggests a much sharper boundary: five generic state/action
pairs identify the shared action when the probes span at least two triality
views, whereas four mixed-view probes or five probes in one view leave a
three-dimensional stabilizer.

This experiment freezes that observation as a theorem-and-training gate. The
rank pattern has been observed; none of the training, adversarial-witness, or
long-composition outcomes below has been inspected.

## Geometric hypothesis

For generic probes, successive constraints reduce the connected stabilizer by

\[
\operatorname{Spin}(8)\supset \operatorname{Spin}(7)\supset G_2
\supset SU(3)\supset SU(2)\supset \{e\},
\]

with dimensions

\[
28,\ 21,\ 14,\ 8,\ 3,\ 0.
\]

Consequently:

1. any four generic probes distributed over at least two triality views leave
   an infinitesimal `SU(2)` stabilizer of dimension three;
2. five generic probes distributed over at least two views have full
   differential rank 28;
3. five probes in one eight-dimensional representation have rank 25, because
   five generic vectors still have an `SO(3)` pointwise stabilizer;
4. the same `(1 vector, 4 positive-spinor, 0 negative-spinor)` evidence has
   rank only `7 + 22 = 29` in three independently parameterized `SO(8)`
   actions, leaving `84 - 29 = 55` tangent directions unconstrained.

The group-intersection interpretation is motivated by the standard triality
description of `G2` as the intersection of two nonconjugate `Spin(7)`
stabilizers and the stabilizer chain through `SU(3)` and `SU(2)`. The numerical
gate below is required because the present experiment concerns a particular
real matrix realization and generic probe construction, not merely abstract
dimension counting.

## Frozen variants

Each token receives fixed, deterministic, orthonormal input probes and the
teacher-transformed outputs. No action matrix column is supplied directly.

| Variant | Probe allocation `(V, S+, S-)` | Parameters per token | Purpose |
|---|---:|---:|---|
| `shared_five_mixed` | `(1, 4, 0)` | 28 shared | Proposed minimal identifiable family; all `S-` action is hidden |
| `shared_four_mixed` | `(1, 3, 0)` | 28 shared | One-probe-short stabilizer control |
| `shared_five_single` | `(5, 0, 0)` | 28 shared | Same evidence count without multiview triality |
| `independent_five_mixed` | `(1, 4, 0)` | 84 independent | Fits visible endpoints without shared-family retraction |
| `oracle` | full teacher | supplied | Numerical ceiling |

All learned variants use the same teacher families, initialization scale,
Adam/L-BFGS budget, float64 arithmetic, and endpoint MSE objective. The
independent control has strictly more parameters; no parameter-count advantage
is granted to the shared model.

## Exact four-probe non-identifiability witness

For every seed, form the Jacobian at the identity of the `(1, 3, 0)` probe
observation map and extract a nonzero tangent vector `X` from its
three-dimensional nullspace. Its exponentiated shared action `S = exp(X)`
fixes every visible probe. For a teacher family `Q`, define

\[
Q'_r = Q_r S_r,\qquad r\in\{V,S^+,S^-\}.
\]

`Q` and `Q'` must give the same four visible endpoints while disagreeing on
hidden `S-` states. This is a constructive ambiguity certificate, independent
of optimizer behavior.

## Frozen cohort and evaluation

- development smoke: seed 0 only;
- reliability cohort: seeds 0-9, with identical hyperparameters fixed after
  the smoke;
- dense word lengths: 16, 32, 64, 128, 256, 512, 1024, 2048;
- all random probes are generated by a canonical CPU float64 stream before
  transfer to the selected device;
- all variants are evaluated on the same unseen states and token words.

## Frozen gates

### A. Differential rank gate

Across every seed:

- `(1, 3, 0)` has shared rank 25 and nullity 3;
- `(1, 4, 0)` has shared rank 28 and nullity 0;
- `(5, 0, 0)` has shared rank 25 and nullity 3;
- independent `(1, 4, 0)` has rank 29 and nullity 55.

The full allocation audit for totals 1-5 must reproduce these rank envelopes:

| Total probes | One view | At least two views |
|---:|---:|---:|
| 1 | 7 | n/a |
| 2 | 13 | 14 |
| 3 | 18 | 20 |
| 4 | 22 | 25 |
| 5 | 25 | 28 |

### B. Constructive ambiguity gate

For every seed, the four-probe witness must satisfy:

- visible maximum absolute endpoint error below `1e-9`;
- hidden negative-spinor mean cosine below `0.99` on unseen states;
- both original and alternative families satisfy triality equivariance below
  `1e-9`.

### C. Optimization and completion gate

Every learned control must fit its supplied endpoints below `1e-8` MSE. At
least 8/10 `shared_five_mixed` seeds must additionally satisfy:

- hidden `S-` one-step mean cosine at least `0.9999`;
- triality-equivariance maximum error below `1e-8`;
- nontrivial vector commutator at least 90% of the oracle value;
- mean cosine at least `0.999` in every representation at every dense length;
- absolute log-norm drift below `1e-5`;
- associative-scan/recurrent maximum error below `1e-9`.

### D. Causal separation gate

In at least 8/10 seeds, `shared_five_mixed` must beat both
`independent_five_mixed` and the strongest underidentified shared control by at
least `0.05` in hidden-`S-` one-step cosine and by at least `0.05` in the worst
representation at length 2048.

## Interpretation boundaries

- Passing proves generic local identifiability and reliable recovery in this
  sampled neighborhood. It does not, by itself, prove global uniqueness modulo
  the finite center of `Spin(8)`.
- The exact four-probe witness proves necessity for the frozen observation
  design; failure of a learned four-probe model is not used as that proof.
- Five probes are not claimed sufficient if all probes occupy one
  representation, if probes are nongeneric, or if token actions are normalized
  independently.
- This is an action-identification experiment, not yet a language-model or
  semantic-alias result.
