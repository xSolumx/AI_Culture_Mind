# Referee packages

Referee packages are compact, claim-specific review objects. Each package must
contain a sharply scoped statement, human-readable proof, explicit trust
boundary, independently reconstructed verifier where feasible, exact artifacts,
hashes, nonclaims, and a short reproduction path.

| Package | Scope | Verification boundary |
|---|---|---|
| [Balanced Cayley information spectrum](cayley-information-spectrum/README.md) | Exact spectrum and aligned design criteria on the canonical orthonormal balanced family; orbit-completeness stated separately | Standard-library verifier independently rederives all consequences of the four supplied block laws |

The chronological experiment archive is not required reading for these
packages. It remains the provenance record for how the claims were discovered,
corrected, and narrowed.
