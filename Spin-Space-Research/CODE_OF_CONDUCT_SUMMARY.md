# Code of Conduct — Short summary and translations

## English (short)
Be respectful, follow the AGPL-3.0 license and preserve attribution. Report concerns using the repository's Code of Conduct report template or by emailing haydaust@gmail.com.

## Español (resumen)
Sea respetuoso, siga la licencia AGPL-3.0 y conserve la atribución. Informe problemas usando la plantilla de informe del Código de Conducta del repositorio o enviando un correo a haydaust@gmail.com.

## Français (résumé)
Soyez respectueux, respectez la licence AGPL-3.0 et conservez les mentions d'attribution. Signalez les problèmes en utilisant le modèle de rapport du Code de conduite du dépôt ou en envoyant un courriel à haydaust@gmail.com.
