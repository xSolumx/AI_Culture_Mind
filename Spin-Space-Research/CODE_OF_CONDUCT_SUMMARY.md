# Code of Conduct — Short summary and translations

**Research author and maintainer:** Hayden Austin

This companion summary follows the parent Code of Conduct's
[CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/) licence and is
an exception to the repository's Apache-2.0 licence.

## English (short)
Be respectful, follow the Apache-2.0 licence, and preserve attribution. Report
concerns using the repository's Code of Conduct report template or by emailing
haydaust@gmail.com.

## Español (resumen)
Sea respetuoso, siga la licencia Apache-2.0 y conserve la atribución. Informe
problemas usando la plantilla de informe del Código de Conducta del repositorio
o enviando un correo a haydaust@gmail.com.

## Français (résumé)
Soyez respectueux, respectez la licence Apache-2.0 et conservez les mentions
d'attribution. Signalez les problèmes en utilisant le modèle de rapport du Code
de conduite du dépôt ou en envoyant un courriel à haydaust@gmail.com.
