## Scientific claim

Equivariant bilinear drives can be lifted into a triangular affine transition
algebra that remains closed under associative composition. `Spin(8)` triality
provides an exceptional eight-dimensional instance.

## Exact capacity boundary

For unit triality keys, single-pair binding is exactly invertible. With an
`H`-dimensional multiplicity code, `K <= H` orthogonal code columns give exact
linear slot isolation. Raw superposition in one eight-dimensional triality
space does not provide high-capacity associative memory.

## Nonclaims

- Scan closure alone does not imply a production-competitive kernel. The
  stable co-moving compiler now covers supplied noncommuting value transport
  with official FLA kernels, including prefix, inverse-frame solve, and read
  frame in measured time. It uses 128 rather than 64 logical state scalars and
  still excludes address encoders.
- Exact single-pair inversion does not imply high-capacity vector-symbolic
  retrieval.
- Hard/discretized slot routing beats the local learned-key delta row at matched
  64-scalar state and encoder size, but oracle delta is exact. This is an
  address-geometry result, not a failed delta update or a fused-kernel claim.
- Direct and triality slots tie under hard routing. No triality-specific memory
  update advantage has been found.
- The prospective Task B result supports a shared representation prior for
  held-out cross-view action completion. The identical direct/delta rows and
  the separate SO(3) cross-product intertwiner experiment prevent reading it
  as extra memory capacity, a superior update law, or an advantage exceptional
  to triality. The SO(3) row is a matched experiment control, not a maintained
  language model.
- Spin(9) Clifford binding is exact but is a same-width gauge of direct 16-vector
  slots. Its Hopf output is a candidate coarse router, not a fine-memory
  replacement or an established learned advantage.
- The 64-slot campaign measures a real fused gathered-state inference kernel,
  but supplies the inverse action frame and does not test gradients. Its CUDA
  speedups are local hardware results, not triality capacity or model quality.
- In a teacher-aligned identification gate, the known one-dimensional
  intertwiner family extrapolates exactly from a proper coordinate subspace,
  while a generic tensor fit to the same endpoints does not. SO(3) reproduces
  the effect, so this is not a triality-specific win.
