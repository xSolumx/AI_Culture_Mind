# Program 05: Spin(8) Dirac--Gram inequalities

## Object

The strengthened inequality compares a correlated four-probe frame (X) with
its symmetric whitening (Q=(XX^{\mathsf T})^{-1/2}X):

\[
\det I(X)\leq \det(XX^{\mathsf T})^3\det I(Q).
\]

This is a real-algebraic and computer-assisted theorem program. It is not a
sequence-model result and it does not inherit global design optimality from
the orthonormal Cayley family.

- exact signed-star and variable-Cayley one-edge theorems;
- an exact Bernstein atlas on the frozen two-edge `h=0` family;
- exact unrestricted sector reconstruction and local tangent control;
- a global Fourier-energy bound and exact endpoint-face theorems.

## Open gate

nonnegative on the complete feasible seven-variable domain. Aggregate energy,
partial elementary-symmetric invariants, endpoint faces, and successful
counterexample searches do not close that gap.
